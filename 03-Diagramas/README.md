# 03-Diagramas

Pasta para canvases do plugin **Excalidraw** — útil pra recriar/adaptar visualmente diagramas do curso ao nosso projeto (ex: nosso próprio mapa de empatia, nosso duplo diamante, esboço do nosso BMC antes de preencher o canvas oficial).

## Como criar um novo diagrama
1. Instale o plugin community **Excalidraw** (Configurações → Community plugins → procurar "Excalidraw").
2. Clique com o botão direito nesta pasta → **New drawing** (ou use o comando "Excalidraw: Create new drawing").
3. Nomeie de forma descritiva, ex: `Mapa-de-Empatia-Nosso-Publico.md` ou `Duplo-Diamante-Nosso-Problema.md`.

> Não vim com nenhum canvas pronto — o Excalidraw gera um formato de arquivo próprio, então é mais seguro você criar direto pelo plugin do que eu tentar montar um arquivo `.excalidraw` na mão. Se quiser, posso te passar um roteiro de como estruturar um diagrama específico (ex: campos do mapa de empatia) pra você desenhar em cima.
